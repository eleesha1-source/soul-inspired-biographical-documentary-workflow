# Documentary project record

Status: planning / researched / scripted / narration complete / assembled / exported

## Brief
Subject, working title, audience, channel/series, runtime target, ratio, narrator identity, presenter choice, visual style, intended next-view destination.

## Research and script
Source inventory: source ID | title/creator | edition/date | URL/local reference | locator | availability

Claim ledger: claim ID | proposed statement | category | source ID/locator | confidence | open issue

Quote ledger: quote ID | exact text | source/edition/locator | verified | planned use

Track outline, master script version, fact-check status and clean narration version separately.

## Production
Narration log: segment ID | script version | voice identity | job/asset ID | status | measured duration | audio lock

Storyboard: scene ID | chapter | narration segment/claim | measured in/out | mode | visual/motion | overlay | asset IDs

Manifest: asset ID | source/creator | rights category/evidence/territory | credit | reconstruction label | scene | status

Timeline: project ID | audio sequence | actual start/end | visual coverage | save/export identity

## Release package
Titles, thumbnail concept, description/credits, measured chapters, search phrases, pinned-comment draft, playlist, end screen and next-video link. Track publication separately.

## Repurposing and lessons
Shorts, audio, article/newsletter, quote posts and follow-up films. Record tool constraints, repairs, checks performed, limitations and reusable workflow improvements after production.

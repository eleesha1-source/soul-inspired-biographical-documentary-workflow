# Soul-Inspired biographical documentary workflow

Status: working prototype, informed by Florence Scovel Shinn Film #1; not yet production-tested.

## Start here

Use workflow/SYSTEM_PROMPT.md as the customized workflow and projects/florence-scovel-shinn/BRIEF.md as its first project brief. The original files remain untouched under reference/historical-documentary-video-workflow/. See reference/PROVENANCE.md for their pinned source and exact blob hashes.

This branch adds a separate workflow rather than changing the copied prompt. Do not load the reference prompt together with the customized prompt: its fictional presenters, construction-story requirements, fixed style and five-minute cap are upstream defaults, not requirements of this adaptation.

The reusable format is Biography → Ideas → Legacy, for The Soul Whisperer’s “Who Was…?” series. Use Florence production results to revise this prototype before treating it as the permanent playbook.

## Deliverables

Research dossier → outline → master script → fact check → clean narration → storyboard → asset manifest → VideoExpress assembly → upload package → repurposing.

Keep project-specific content in projects/<subject>/ and reusable instructions in workflow/. Use workflow/PROJECT_TEMPLATE.md for later films. No film, narration or source research has been completed by this repository setup.
